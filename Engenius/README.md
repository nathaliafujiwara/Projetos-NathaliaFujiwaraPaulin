# Engenius
  
  Como projeto final de "Introdução A Práticas De Laboratório Em Eletricidade E Eletrônica", na UTFPR, eu e meu grupo desenvolvemos um brinquedo baseado no Genius, da Estrela, que chamamos de "Engenius". O jogador deve replicar uma sequência de cores mostrada pelos LEDs coloridos, sendo cada cor associada a um tom do buzzer. Com o passar das rodadas, a sequência vai ficando cada vez maior e mais rápida, sendo que o "nível" é visível por uma fileira de LEDs vermelhos, que vão acendendo conforme a dificuldade aumenta. Ao completar todos os níveis, um buzzer é acionado, tocando uma musiquinha de comemoração enquanto os LEDs coloridos piscam.

  O controle foi feito com um Arduino UNO e soldamos os componentes em uma placa perfurada. No fim de nossa apresentação, o professor, que tem um projeto de eletrônica educacional, pediu para ficar com o brinquedo, o que aceitamos prontamente. Em troca, ele nos entregou um Arduino UNO novo e outros componentes, para compensar os que demos a ele no Engenius.
