# Tamagotchi
	
Como projeto final da matéria de Eletrônica Digital (no IFPR), a turma foi dividida em duplas e trios para criar uma simulação ou, no caso dos trios, um protótipo físico de um equipamento utilizando principalmente os aprendizados da matéria. Eu e minha dupla, minha irmã gêmea, decidimos desenvolver uma simulação de um bichinho virtual, com base no Tamagotchi, da Bandai Namco. 

Para isso, usamos principalmente portas lógicas e Flip-Flops, com o programa Logisim versão 2.7.1. Nós apresentamos o projeto para a turma e também escrevemos um relatório detalhando seu processo de desenvolvimento e funcionamento.

Em resumo, para cada necessidade do bichinho, fizemos um contador, com durações diferentes para cada uma, e telas para representar o estado dele. Essas imagens foram construídas codificando uma matriz de LEDs até formar uma imagem pixelada — que foi a parte que eu mais gostei de fazer do projeto!

As imagens mudavam de acordo com o tempo restante do contador, gerando uma "animação" com a mudança constante entre duas figuras parecidas. Então, por exemplo, quando o contador de "Comida" estivesse cheio, o pet estaria visivelmente animado, como se estivesse pulando. À medida que o contador fosse diminuindo, porém, o bichinho ficaria cabisbaixo e olhando de um lado para o outro. Caso o contador chegasse a zero, a imagem mudaria para uma sepultura, simbolizando que o Tamagotchi morreu.

P.S.: O arquivo ".circ" foi feito utilizando o programa citado acima. Caso você não o tenha em seu computador, as imagens da simulação final estão disponíveis no relatório e nos slides.
